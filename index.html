VECTOR ANATOMY

រចនាសម្ព័ន្ធ និងសមាសភាគរបស់ Logo (Vector Explorer)

ចុចប៊ូតុងខាងក្រោមដើម្បីមើលប្លង់បន្ទាត់ Wireframe (Outline Mode) ឬបន្ទាត់ Guide នៃរង្វង់នីមួយៗ

របៀបបង្ហាញ (Display Mode):

គំរូវ៉ិចទ័រឆ្លើយតប (SVG Vector Renderer)

កាយវិភាគវិទ្យានៃនិមិត្តសញ្ញា (Graphic Components)

1. អក្សររាងកោងខាងលើ (Top Curved Text):

អក្សរខ្មែរ "សាលាបង្រៀនភេសជ្ជៈ" គូសលើរង្វង់មូលដោយប្រើឧបករណ៍ Type on a Path Tool (Font រាងមូលដូចជា Kantumruy Pro ឬ Khmer OS Muol Light)។

2. អក្សររាងកោងខាងក្រោម (Bottom Curved Text):

អក្សរឡាតាំង "BAVERAGE SCHOOL" ប្រើ Type on a Path Tool រួចចូល Options ជ្រើសរើស Flip ដើម្បីឲ្យអក្សរផ្ងារឡើងលើត្រឹមត្រូវ។

3. ពែងកាហ្វេ និងចានទ្រនាប់ (Coffee Cup & Saucer):

តួពែងប្រើរាងគូទមូល (Pen Tool + Ellipse Tool) មានឆ្នូតពណ៌ស ៤ ឆ្នូតកាត់នៅផ្នែកស្តាំ (Negative Space Highlight) និងចានទ្រ ២ ជាន់។

4. ផ្សែងកាហ្វេ និងគ្រាប់កាហ្វេហោះ (Steam & Accents):

ផ្សែងកោង ២ បន្ទាត់ផុសឡើងលើ អមដោយគ្រាប់កាហ្វេហោះ ២ គ្រាប់ និងរូបបេះដូងតូច ១ នៅខាងស្តាំ។

5. គ្រាប់កាហ្វេអមសងខាង (Side Coffee Beans):

ខាងឆ្វេង ៣ គ្រាប់ និងខាងស្តាំ ៣ គ្រាប់ តម្រៀបតាមរង្វង់កោង ជំនួសឲ្យផ្កាយ ឬចំនុចសាមញ្ញ។
